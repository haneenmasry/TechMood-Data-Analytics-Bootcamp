أهداف المعسكر : 

تأهيلك بالمهارات التقنية (Excel, SQL, Power BI, Python) والمهارات الإدارية والإحصائية اللازمة لتبني بورتفوليو احترافي حقيقي يثبت كفاءتك أمام مديري التوظيف واللجان التقنية للشركات العالمية.



المهارات والأدوات التي سيتم تعلمها خلال المعسكر :

\- الإكسل المتقدم للتحليل المالي وبناء نماذج البيانات (Advanced Excel).

\- لغة الاستعلامات الهيكلية (SQL) لإدارة واستخلاص البيانات من قواعد البيانات.

\- برنامج Power BI Desktop \& Service لبناء ومشاركة لوحات التحكم التفاعلية على السحابة.

\- لغة بايثون (Python) ومعالجة المصفوفات الرياضية عبر NumPy و Matplotlib.

\- الإحصاء الوصفي والاستدلالي واختبار الفرضيات والـ A/B Testing.

\- هندسة قنوات البيانات (ETL) وقواعد رواية القصة بالبيانات (Data Storytelling).
